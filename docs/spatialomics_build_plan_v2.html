03Phase 1

Interactive QC Dashboard NEW

Before the agent runs any analysis, the biologist must see a QC summary and approve it. Skipping this is the single most common cause of downstream garbage results. This is not optional — the API blocks analysis until QC is acknowledged.

Prompt for Claude Code

"In spatialMind/viz/qc/, implement a QCReportBuilder that takes an IngestionReport + raw SpatialData and generates an interactive HTML QC dashboard. It must render: per-sample violin plots (UMI counts, gene counts, % mito), spatial scatter of QC metrics overlaid on tissue, doublet score distribution, and a filtration waterfall (how many spots removed at each step). The agent API must return this dashboard URL and require qc_approved=True in the next request before proceeding."

Violin plots per QC metric
nUMI, nGenes, pct_mito, pct_ribo per sample. Highlight outlier spots. Threshold lines shown as draggable (future interactive feature).
Spatial QC overlay
Plot nUMI and pct_mito on tissue coordinates. Low-quality spatial zones visible immediately — critical for slide artifacts.
Filtration waterfall chart
Shows: raw spots → after min_counts filter → after min_genes → after mito filter → after doublet removal. Makes data loss visible.
Gene detection rate heatmap
For multi-sample: which genes are detected in ≥80% of samples. Flags genes that will be noisy in cross-sample analyses.
QC gate in API
NEW POST /sessions/{id}/approve-qc endpoint. Agent checks qc_approved flag before executing any tool. Unapproved sessions return 403.

06Phase 2

Algorithm Implementations

Implement all 22 tool callables. Key upgrade from v1: every wrapper must handle real-world data failure modes, not just happy-path execution. Each implementation file has a corresponding test using real public datasets.

Prompt for Claude Code

"Implement all 22 SpatialTool callables in spatialMind/tools/implementations/. For each: validate inputs using the precondition checker, wrap the algorithm, handle the 5 typed exceptions (InsufficientDataError, MissingPreconditionError, AlgorithmConvergenceError, InvalidParameterError, DataModalityError). Use public benchmark datasets for tests: spatialLIBD for Visium, MIBI-TOF breast cancer for IMC, 10x Xenium lung for single-molecule."

Critical real-data issues each wrapper must handle

CNV inference: needs ≥50 normal reference cells or raises InsufficientDataError. Cell2location: fails gracefully if scRNA reference has different gene set — intersects and warns. SpatialDE2: minimum 100 spots required, raises with specific count if below. LIANA: some databases require internet access — cache OmniPath locally on first run. Cellpose: GPU detection + CPU fallback with runtime warning.

# New: DataModalityError for wrong data type
class DataModalityError(SpatialToolError):
    """Raised when a tool is called on wrong data type.
    e.g. protein_coexpression called on RNA data."""
    def __init__(self, tool: str, got: str, expected: str):
        super().__init__(
            f"{tool} requires {expected} data, got {got}. "
            f"Use {suggest_alternative(tool, got)} instead."
        )
07Phase 2

Multi-modal Data Fusion NEW

The most scientifically powerful capability: combining scRNA-seq + Visium + IMC from the same tissue. This is not a single tool — it's a fusion layer that aligns multiple modalities into a shared coordinate space so downstream tools can query across all of them simultaneously.

Prompt for Claude Code

"In spatialMind/tools/fusion/, implement a ModalityFuser class. It accepts a list of SpatialData objects from different modalities and aligns them: (1) scRNA + Visium: transfer cell-type labels via Cell2location, (2) Visium + H&E: register molecular coordinates to tissue morphology, (3) IMC + Visium: spatial join by nearest-neighbor if coordinates overlap, (4) Visium + ATAC: link gene expression peaks to open chromatin per spot. Output a FusedDataset with a shared obs/var space and provenance of which data came from where."

12Phase 4

Report Generator MAJOR UPGRADE

v1 report = one text string. v2 generates a structured, multi-section HTML report (exportable to PDF) that a researcher can send to a PI or attach to a manuscript. Sections are auto-generated from the tool trace and results — the LLM writes interpretations per section, not just one final summary.

Prompt for Claude Code

"In spatialMind/viz/report/, implement a ReportBuilder that takes an AgentResponse (or BatchJobResult) and generates a full HTML report. Structure: Executive Summary, Data Quality, Methods, Results (one subsection per tool run), Figures Gallery, Statistical Summary table, and Appendix (full provenance). Export to PDF via WeasyPrint. Each section is independently generated by a separate LLM call with section-specific context."

Report Structure Preview — what gets generated
1 · Executive Summary
LLM-generated 3–5 sentence summary of key findings. Includes: primary biological conclusion, statistical confidence, and one recommended follow-up experiment. Written for a PI-level audience.
2 · Data Quality Report
QC dashboard embedded. Filtration waterfall. Per-sample quality flags. n=12,450 spots passed QC median UMI: 3,241 2 samples flagged: low spot density
3 · Methods
Auto-generated methods section with exact software versions, parameter values, and citations. Ready to paste into a manuscript Methods section. Formatted as: "Cell type deconvolution was performed using Cell2location v0.1.3 (Kleshchevnikov et al. 2022) with [params]..."
4 · Results (per tool)
One subsection per tool executed. Each contains: figure, statistical output table, LLM interpretation paragraph. Example: CD8+ T cells: z-score 3.4 p < 0.001 immune-excluded phenotype
5 · Figures Gallery
All figures at full resolution with captions. Interactive HTML versions linked. Download individual figures as SVG/PNG.
6 · Statistical Summary Table
All computed statistics in one table: metric, value, test used, sample size, p-value, adjusted p-value, effect size. Machine-readable CSV export included.
7 · Appendix — Full Provenance
Complete tool trace with timestamps. All parameter values. Software version manifest. Reproducibility hash. "To reproduce: spatialMind replay --run-id {uuid}"
# spatialMind/viz/report/builder.py
class ReportBuilder:
    def build(
        self,
        response: AgentResponse | BatchJobResult,
        format: Literal["html", "pdf", "both"] = "both"
    ) -> ReportPaths:
        sections = [
            self._executive_summary(response),   # LLM call
            self._data_quality(response),         # from IngestionReport
            self._methods_text(response),          # LLM call with citations
            self._results_per_tool(response),      # LLM call per tool
            self._figures_gallery(response),       # embed figures
            self._stats_table(response),           # structured extraction
            self._provenance_appendix(response),   # from RunRecord
        ]
        return self._render(sections, format)
